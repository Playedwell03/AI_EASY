# AI Easy — 클릭하며 배우는 딥러닝 실습 사이트 (설계 문서)

## 1. 의도와 이유

AI를 처음 접하는 사람이 딥러닝 각 분야의 **대표 구조**를 직접 클릭하며 살펴보고, 브라우저 안에서 **학습 → 검증 → 테스트**를 직접 돌려 보며, 무엇보다 **"이 학습이 잘 된 것인지"를 증거(그래프·지표·예시)로 판단하는 법**을 익히게 하는 웹사이트.

이론 설명을 읽는 사이트가 아니라, 버튼을 눌러 보고 결과를 눈으로 보며 이해하는 사이트다.

## 2. 대상 사용자

- AI를 처음 접하는 사람. 수식·코드 지식을 전제하지 않는다.
- 모델이 어떻게 돌아가는지 탐구하고, 학습을 돌려 보고, 그래프를 보며 "잘 됐다/안 됐다"의 근거를 알고 싶어 한다.

## 3. 목표 / 비목표 / 반목표

**목표**
- 9개 분야 모듈 각각에서 구조 보기 → 데이터 → 학습 → 진단 → 테스트를 전부 클릭으로 체험.
- 학습이 실시간으로 보이고(손실·정확도 곡선 등), "잘 된 건가?"에 대해 판정 + 근거를 쉬운 말로 제공.
- 설치·서버 없이 링크/파일만 열면 동작.
- 한국어/영어 전환.

**비목표**
- 실제 대형 모델(GPT, BERT-base 등) 학습·추론. 대표 구조를 작게 쌓은 축소판으로 대신한다.
- Python/PyTorch 백엔드, 계정·로그인, 결과 저장 서버.
- 최신 SOTA 성능.

**반목표 (기술적으로 돌아가도 실패로 보는 것)**
- 숫자·용어만 잔뜩 나오고 "그래서 잘 된 거야?"에 답하지 않는 화면.
- 학습이 너무 오래 걸려(1~2분 이상) 초보자가 기다리다 떠나는 구성.
- 브라우저가 멈추는(UI 프리즈) 학습.
- 설명 없이 전문 용어만 던지는 문구.

## 4. 결정된 사항 (사용자가 정함)

- **학습은 브라우저 안에서** 실행한다.
- **분야**: 기초 신경망(MLP), 이미지(CNN), 언어(RNN, Transformer), BERT 계열, 생성(오토인코더/VAE), 시계열, 음성, Jev 스타일 결정 모델. 무거운 모델은 대표 구조대로 가볍게 쌓는다.
- **언어**: 한국어 + 영어 전환 버튼.
- 공통 틀 + MLP 모듈을 먼저 완성하고 나머지 모듈을 순서대로 붙인다.

## 5. 공통 학습 흐름 (모든 모듈 동일한 5단계 탭)

1. **구조(Architecture)** — 층 다이어그램. 층을 클릭하면 역할 설명, 입력/출력 텐서 모양, 파라미터 수가 나온다. 일부 하이퍼파라미터(층 수, 크기)는 여기서 바꿀 수 있고 다이어그램이 갱신된다.
2. **데이터(Data)** — 샘플 미리보기, 학습/검증/테스트 분할 비율과 개수를 시각적으로 보여 주고 "왜 셋으로 나누는가"를 설명.
3. **학습(Train)** — 시작/일시정지/초기화, 학습률·배치 크기·에폭 조절. 학습 곡선(train vs. validation)이 실시간으로 그려진다. 학습 중 모델 내부(결정 경계, 필터, 재구성 이미지 등)가 함께 변화하는 시각화가 있는 모듈은 함께 보여 준다.
4. **진단(Diagnose) — "잘 된 건가?"** — 곡선 모양으로 자동 판정: 정상 학습 / 학습 부족(underfitting) / 과적합(overfitting) / 발산·불안정. 판정마다 **근거**(예: "검증 손실이 12에폭부터 다시 올라갔습니다")와 **다음에 해 볼 것**(예: "에폭을 줄이거나 드롭아웃을 켜 보세요")을 쉬운 말로 제시. 모듈별 핵심 지표(정확도, 혼동행렬, 퍼플렉서티, MSE, ECE 등)를 "이 숫자가 뜻하는 것" 설명과 함께 보여 준다. 기준선(무작위 추측 수준)과 비교해 "우연보다 얼마나 나은가"를 항상 표시.
5. **테스트(Test)** — 학습에 쓰지 않은 테스트셋 결과 + 사용자가 직접 입력해 보는 놀이터(그리기, 문장 입력, 슬라이더 등) + 틀린 예시 모음.

추가로 각 모듈에 **"일부러 망가뜨려 보기"** 프리셋 버튼(학습률 너무 크게, 데이터 너무 적게 등)을 두어 과적합·발산을 직접 재현하고 진단 패널이 그것을 잡아내는 것을 체험하게 한다.

## 6. 모듈 목록

| # | 모듈 | 대표 구조 (축소판) | 데이터 (브라우저 내 생성/내장) | 핵심 "잘 됐다" 증거 |
|---|------|------|------|------|
| 1 | 기초 신경망 MLP | Dense 층 쌓기, 활성화 함수 선택 | 2D 점 분류(원형, 나선, XOR 등) 합성 | 결정 경계 시각화, train/val 손실·정확도 |
| 2 | 이미지 CNN | Conv→Pool→Conv→Pool→Dense | 손글씨 숫자 (작은 내장 데이터셋 또는 캔버스로 합성 생성) | 혼동행렬, 필터·특징맵 시각화, 직접 그린 숫자 인식 |
| 3 | 언어 RNN | 임베딩→LSTM/GRU→Dense (글자 단위) | 내장된 짧은 텍스트 코퍼스 | 손실·퍼플렉서티, 학습 진행에 따른 생성 문장 변화 |
| 4 | 언어 Transformer | 임베딩+위치인코딩→Self-Attention 블록 1~2개→Dense (디코더, 글자 단위) | 동일 코퍼스 | 퍼플렉서티, 어텐션 맵 시각화, 생성 문장 |
| 5 | BERT 계열 | 양방향 인코더 + MLM(빈칸 맞히기) 헤드 | 동일/별도 짧은 문장 코퍼스 | 마스크 예측 정확도, 상위 후보 확률, 직접 [MASK] 넣어 보기 |
| 6 | 생성 AE/VAE | 인코더→잠재공간(2D)→디코더 | 숫자 이미지(모듈 2와 공유) | 재구성 오차, 원본 vs 재구성, 2D 잠재공간 지도, 잠재 슬라이더로 생성 |
| 7 | 시계열 | 슬라이딩 윈도우 → LSTM 또는 1D Conv → 다음 값 예측 | 합성 시계열(추세+계절성+노이즈) | MSE/MAE, **단순 기준선(직전 값 그대로) 대비 개선**, 예측 vs 실제 그래프 |
| 8 | 음성 | 스펙트로그램 → 작은 CNN | 합성 소리(톤, 상승/하강 처프, 노이즈 등) 몇 종류; 마이크 입력은 선택 기능 | 혼동행렬, 스펙트로그램 시각화, 직접 소리 들어보고 맞히기 |
| 9 | Jev 스타일 결정 모델 | 상태 필드를 토큰화 → 작은 Transformer 인코더 → 질문 유형별 헤드(선택=softmax, 점수=회귀, 예/아니오=sigmoid) | 합성 표형 데이터(예: 대출 승인, 문의 라우팅) | 정확도 + **보정 그래프(reliability diagram)와 ECE**: "80% 확신일 때 실제로 80% 맞나" |

Jev 참고: TypeSafe AI가 2026년 9월 공개한 Transformer 기반 결정 모델로, 텍스트를 생성하지 않고 상태 + 형식이 정해진 질문을 받아 보정된 확률/점수를 반환한다. 이 모듈은 그 **아이디어를 재현한 교육용 축소판**이며 실제 Jev와 무관함을 화면에 명시한다.

## 7. 제약

- 정적 사이트: 서버 코드 없음. 로컬에서 파일을 열거나 아무 정적 호스팅에 올려 동작.
- 외부 데이터셋 다운로드에 의존하지 않는다(오프라인/차단 환경 고려). 데이터는 내장하거나 브라우저에서 생성.
- 각 모듈의 기본 설정 학습은 일반 노트북에서 **약 1분 이내**에 의미 있는 결과가 나와야 한다.
- 학습 중 UI가 멈추지 않아야 한다(에폭/배치 사이 양보 또는 Web Worker).
- 데스크톱 우선, 모바일에서도 깨지지 않고 읽을 수 있을 것.
- 모든 UI 문구는 한국어/영어 두 벌. 전문 용어는 "손실(Loss)"처럼 병기.

## 8. 빌더에게 맡기는 것 (내가 정한 기본값은 [기본값] 표시)

- 프레임워크: [기본값] 빌드 단계 없는 순수 HTML/CSS/JS(ES 모듈) + **TensorFlow.js**(CDN). 필요하다면 빌더가 가벼운 번들러(Vite)를 써도 되지만 결과물은 정적 파일이어야 한다.
- 차트: [기본값] 직접 만든 가벼운 Canvas/SVG 차트 또는 CDN 차트 라이브러리. 다크/라이트 모두 읽혀야 한다.
- 페이지 구조: [기본값] 홈(모듈 카드 목록 + "처음이라면 여기부터" 안내) + 모듈별 페이지(5단계 탭). 해시 라우팅.
- 시각 디자인, 색, 폰트, 아이콘.
- 각 모듈의 정확한 하이퍼파라미터 기본값과 데이터 크기(제약 7의 시간 한도 안에서).
- 진단 판정의 구체적 임계값.
- 손글씨 숫자 데이터를 어떻게 확보할지(작게 압축해 내장 vs 폰트 렌더링+변형으로 합성).

## 8-1. 리뷰 후 정한 사항 (모두 내 판단 — 사용자 확인 필요 시 표시)

- **범위**: 최종 목표는 9개 모듈 전부. 마일스톤 1 = 공통 틀 + MLP, 이후 모듈마다 하나씩 마일스톤. 그래서 공통 학습 루프·진단·시각화 인터페이스는 처음부터 9개 모듈이 끼워질 수 있게 설계한다.
- **배포 형태**: 정적 호스팅(또는 로컬 정적 서버, `python3 -m http.server` 등) 기준. 파일 더블클릭(file://) 지원은 요구하지 않는다. 따라서 ES 모듈·Web Worker·CDN 사용 가능. "외부 의존 금지"는 **데이터셋**에만 적용하고, 라이브러리 CDN은 허용.
- **하드웨어 목표**: GPU 없는 보통 노트북에서도 기본 설정 학습이 약 1분 이내. TF.js WebGL 백엔드 우선, 불가 시 CPU/WASM 대체. 모델 크기는 이 기준에 맞춘다. 모바일은 화면이 깨지지 않는 것까지 보장, 학습 속도는 보장하지 않음.
- **TF.js**: 기본값이며, 어텐션·MLM 헤드·VAE 재매개변수화 등은 TF.js 커스텀 레이어/저수준 연산으로 구현해도 된다.
- **진단**: 공통 곡선 판정기(train/val 손실 기반: 정상/학습 부족/과적합/발산) + **모듈별 추가 판정**을 둔다. 예: VAE는 재구성 오차와 KL, 시계열은 기준선 대비 개선, Jev는 보정(ECE). 각 모듈이 자기 판정 규칙과 근거 문구를 등록하는 구조.
- **"망가뜨려 보기" 프리셋**: 고정 시드로 결과를 재현 가능하게 한다. 일반 학습은 시드 랜덤(초기화 버튼에서 시드 표시).
- **데이터**: 손글씨 숫자·음성은 합성 데이터로 충분하다. 단 화면에 "합성 데이터"임을 표시한다.

## 9. 구현 순서

1. 공통 틀: 홈, 모듈 페이지 뼈대(5 탭), 언어 전환, 차트 컴포넌트, 학습 루프/진단 엔진 공통 코드.
2. 모듈 1 MLP (공통 틀 검증용).
3. 이후: CNN → AE/VAE → 시계열 → RNN → Transformer → BERT → 음성 → Jev. (빌더가 의존성에 따라 조정 가능)

## 10. 성공 기준

- 초보자가 아무 모듈이나 열어 기본 설정으로 "학습 시작"만 눌러도 1분 안에 그래프와 함께 "잘 학습되었습니다 — 근거: …" 판정을 받는다.
- "망가뜨려 보기" 프리셋을 누르면 진단이 과적합/발산을 정확히 짚는다.
- 모든 모듈에서 테스트 탭의 직접 입력이 동작한다.
