# AI Easy Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 정적 웹사이트에서 9개 딥러닝 모듈을 각각 구조→데이터→학습→진단→테스트 5단계로 클릭하며 체험하고, 브라우저 안에서 학습한 결과가 "잘 됐는지"를 근거와 함께 판정받게 한다.

**Architecture:** 빌드 단계 없는 ES 모듈 정적 사이트. 프레임워크 독립 코어(`js/core/`: 난수·분할·지표·진단·학습 루프)와 UI 셸(`js/ui/`: 라우터·탭·차트·i18n)이 있고, 각 모듈(`js/modules/<id>/`)은 공통 `ModuleDef` 인터페이스를 구현해 끼워진다. 모델 코드는 `tf`를 인자로 받으므로 브라우저(CDN의 `window.tf`)와 Node 테스트(`@tensorflow/tfjs` devDependency) 양쪽에서 같은 코드가 돈다.

**Tech Stack:** HTML/CSS/vanilla JS (ES2022 modules), TensorFlow.js 4.x (CDN: `https://cdn.jsdelivr.net/npm/@tensorflow/tfjs@4.22.0/dist/tf.min.js`), 테스트는 Node 22 내장 `node --test` + devDependency `@tensorflow/tfjs@4.22.0`. 차트는 자체 Canvas 구현.

**Spec:** `docs/superpowers/specs/2026-10-17-ai-easy-design.md`

## Global Constraints

- 서버 코드 없음. 정적 호스팅 또는 `python3 -m http.server`로 동작. file:// 지원 불필요.
- 데이터셋은 외부 다운로드 금지 — 내장 또는 브라우저 생성. 라이브러리 CDN은 허용.
- 각 모듈 기본 설정 학습은 GPU 없는 보통 노트북에서 약 1분 이내에 의미 있는 결과.
- 학습 중 UI 프리즈 금지: 매 배치 묶음/에폭마다 `await tf.nextFrame()`.
- 모든 UI 문구는 `ko`/`en` 두 벌. 전문 용어는 "손실(Loss)" 형식 병기(ko).
- 합성 데이터를 쓰는 모듈은 데이터 탭에 "합성 데이터 / Synthetic data" 배지 표시.
- Jev 모듈은 "TypeSafe AI의 Jev 아이디어를 재현한 교육용 축소판이며 실제 Jev와 무관" 문구를 구조 탭에 표시.
- 다크/라이트 모두 읽힘. 360px 폭에서 가로 스크롤 없음.
- WebGL 백엔드 우선, 실패 시 `cpu`로 대체하고 상단에 안내 표시.

## Review Focus

1. 학습 중 "시작"을 다시 누르거나 다른 모듈로 이동 → 루프는 하나만 돌고, 이전 세션은 `dispose()`되어 텐서 누수 없음. → Task 4 테스트.
2. 손실이 NaN/Infinity가 됨(학습률 과대) → 학습 자동 정지, 진단 "발산", 차트는 마지막 유한 값까지만 그림. → Task 2, Task 4 테스트.
3. 1~2 에폭만 돌리고 진단 탭을 엶 → "판단하기엔 아직 이릅니다"(insufficient), 거짓 판정 금지. → Task 2 테스트.
4. 학습 중 언어 전환 → 학습은 계속되고 문구만 바뀜. → Task 3 수동 검증 단계.
5. 마이크 권한 거부/미지원 → 안내 메시지, 합성 소리 테스트는 정상. → Task 12 수동 검증 단계.

### Task 2: 진단 엔진

**Files:**
- Create: `js/core/diagnose.js`
- Test: `tests/diagnose.test.js`

**Interfaces:**
- Consumes: 없음
- Produces: `diagnoseCurves(history: {trainLoss:number, valLoss:number}[], { baselineLoss: number }) -> { verdict: 'insufficient'|'diverged'|'underfitting'|'overfitting'|'good', stillImproving: boolean, bestEpoch: number /*1-based*/, findings: Finding[], advice: string[] /*i18n 키*/ }`

판정 규칙 (위에서부터 첫 번째 일치):
1. 어떤 손실이든 비유한값, 또는 마지막 trainLoss > 3 × 첫 trainLoss → `diverged`, advice `['adv.lowerLr']`
2. `history.length < 3` → `insufficient`, advice `['adv.trainMore']`
3. m = valLoss 최소 인덱스. 마지막 valLoss > 1.10 × valLoss[m] 이고 (last − m) ≥ 3 이고 마지막 trainLoss < trainLoss[m] → `overfitting`, finding `{key:'f.valRoseAfter', vars:{epoch:m+1, pct}}`, advice `['adv.earlyStop','adv.regularize','adv.moreData']`
4. 마지막 trainLoss > 0.8 × baselineLoss, 또는 (첫−마지막)/첫 trainLoss < 0.10 → `underfitting`, advice `['adv.biggerModel','adv.trainMore','adv.raiseLr']`
5. 그 외 `good`, finding `{key:'f.beatsBaseline', vars:{ratio: baselineLoss/마지막 valLoss}}` 및 `{key:'f.gapSmall', vars:{gapPct}}`
- `stillImproving`: 길이 ≥4이고 valLoss[last] < 0.98 × valLoss[last−3]. true면 advice에 `'adv.trainMore'` 추가 (중복 없이).

- [ ] **Step 1: 실패하는 테스트** — 규칙마다 하나씩:
  - `[{2,2},{NaN,NaN}]` → diverged; `[{1,1},{2,2},{4,4}]` → diverged (4 > 3×1).
  - 2개 항목 → insufficient (Review Focus 3).
  - train 1.0→0.1 감소, val 1.0,0.6,0.4,0.5,0.55,0.6 → overfitting, bestEpoch 3.
  - baseline 0.69, train 0.68,0.67,0.66 → underfitting.
  - baseline 0.69, train 0.6,0.3,0.15,0.1, val 0.62,0.32,0.18,0.14 → good, stillImproving true.
- [ ] **Step 2:** `npm test` → FAIL.

### Task 5: 모듈 1 — MLP (2D 점 분류)

### Task 7: 모듈 6 — 오토인코더 / VAE

- Files: `js/modules/vae/*`, `tests/vae.test.js`
- Consumes: `makeDigits`
- 구조: 토글 `variational`(기본 true). 인코더 Dense(400→128→2 [μ, logσ²]) → 재매개변수화(z = μ + ε·exp(½logσ²), 커스텀 학습 루프 `tf.variableGrads`) → 디코더 Dense(2→128→400, sigmoid). 손실 = BCE 재구성 + β·KL (β 기본 1). AE 모드는 KL 없음.
- 지표: 재구성 오차, KL. baseline = 평균 이미지로 재구성했을 때의 BCE.
- 학습 시각화: 원본 vs 재구성 8쌍; 2D 잠재공간 산점도(숫자별 색).
- 진단 추가: KL≈0(<0.01)이면 `f.posteriorCollapse` warn; 재구성 오차가 baseline의 50% 이하면 good finding.
- 테스트 탭: 잠재공간 클릭/슬라이더 2개로 z 선택 → 디코딩 이미지; 8×8 잠재 격자 생성 그림.
- 성공 지표: 테스트 재구성 BCE < 0.6 × baseline. 프리셋: `diverge {lr:0.5}`, `underfit {hidden:4, epochs:2}` expect `'underfitting'`.

- 성공 지표: yes/no 테스트 정확도 ≥ 0.8, ECE ≤ 0.08. 프리셋: `overfit {n:150, epochs:200}` expect `'overfitting'` (진단에 ECE 악화 finding도 기대), `diverge {lr:2}`.
