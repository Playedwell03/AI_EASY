# AI Easy — 클릭하며 배우는 딥러닝

AI를 처음 접하는 사람을 위한 실습 사이트입니다. 딥러닝 아홉 분야의 대표 구조를 작게 줄여 두었고, 브라우저 안에서 직접 학습시킨 뒤 "정말 잘 배운 걸까?"를 그래프와 근거로 확인할 수 있습니다. 학습한 모델을 실제 서비스를 흉내 낸 작은 앱에 넣어 써 보는 체험도 있습니다. 서버나 설치는 필요 없습니다.

## 실행

정적 파일만 있으면 됩니다. ES 모듈을 쓰기 때문에 파일을 더블클릭해서는 열리지 않고, 웹 서버로 열어야 합니다.

```bash
npm run serve        # python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

GitHub Pages, Netlify 같은 정적 호스팅에 폴더를 그대로 올려도 됩니다. TensorFlow.js와 웹 폰트만 인터넷(CDN)에서 불러오고, 데이터는 모두 브라우저 안에서 만들어집니다.

## 모듈

모든 모듈은 같은 6단계로 진행됩니다: **구조 → 데이터 → 학습 → 진단 → 테스트 → 활용**

| # | 모듈 | 대표 구조 | 활용 체험 |
|---|---|---|---|
| 1 | 기초 신경망 (MLP) | Dense 층 | 스팸 필터, 공장 품질 검사, 게임 NPC |
| 2 | 이미지 분류 (CNN) | Conv → Pool | 우편번호 분류, 손글씨 계산기, 숫자 자물쇠, 영수증 합산 |
| 3 | 생성 모델 (AE / VAE) | 인코더 → 2D 잠재공간 → 디코더 | 불량품 탐지, 노이즈 제거, 새 글자 생성, 초압축 전송 |
| 4 | 시계열 예측 | LSTM / Conv1D | 자동 발주, 전력 수요 대비, 트래픽 이상 알림 |
| 5 | 언어 모델 (RNN) | GRU / LSTM | 키보드 자동완성, 이야기 생성, 오타 의심 표시 |
| 6 | 언어 모델 (Transformer) | 마스크드 셀프 어텐션 | 검색어 자동완성, 음성 인식 후보 고르기, 대화 이어 쓰기 |
| 7 | 빈칸 맞히기 (BERT) | 양방향 어텐션 + MLM | 지워진 글자 복원, 오타 교정, 비슷한 문장 찾기 |
| 8 | 소리 인식 | 스펙트로그램 → CNN | 스마트홈 알림, 소리 리모컨, 기계 소리 모니터링 |
| 9 | 결정 모델 (Jev 스타일) | 항목 토큰 + 형식 질문 토큰 → 인코더 | 대출 심사, 자동 배정, 자동 처리 vs 사람 검토 |

9번은 TypeSafe AI가 2026년 9월 공개한 Jev의 아이디어를 교육용으로 재현한 것이며, 실제 Jev와는 무관합니다.

## "잘 배웠나?" 진단

진단 탭은 학습 손실과 검증 손실 곡선, 그리고 "아무것도 모르고 찍었을 때"의 손실(기준선)을 비교해 다섯 가지 중 하나로 판정하고, 근거와 다음에 해 볼 것을 보여 줍니다.

- 잘 학습됨
- 학습 부족
- 과적합
- 발산
- 판단하기 이름

모듈마다 고유한 검사도 더해집니다.

- 이미지·소리: 혼동 행렬
- 시계열: "직전 값 그대로" 예측과의 비교
- 언어 모델: 퍼플렉서티
- 결정 모델: 보정(ECE)

학습 탭의 **"일부러 망가뜨려 보기"** 버튼을 누르면 과적합이나 발산을 직접 재현하고, 진단이 이를 잡아내는 것을 볼 수 있습니다.

## 개발

```bash
npm install
npm test            # 빠른 테스트: 로직, 데이터, 화면 계약 (몇 초)
npm run test:slow   # 학습 품질과 프리셋 판정까지 (오래 걸림)
```

학습 시간 기준(기본 설정으로 약 1분)은 브라우저에서 확인합니다. 학습은 이 탭을 화면에 띄워 둔 상태에서 진행해야 합니다. 브라우저는 백그라운드 탭의 작업을 늦추기 때문입니다.

## 구조

```
index.html, css/style.css
js/app.js, router.js, i18n.js, registry.js
js/core/      난수, 데이터 분할, 지표, 진단 엔진, 학습 실행기
js/ui/        차트, 모듈 6탭 화면, 활용 탭, 어텐션·소리·그리기 도구
js/shared/    손글씨 숫자, 연습 문장, 어텐션 블록, 오디오(STFT)
js/modules/   모듈별 index.js(화면), model.js(모델), data.js, uses.js(활용 체험)
tests/        node --test
```
